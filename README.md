# 📟 Mini Bloomberg Terminal v9.0

A real-time, multi-pane Terminal User Interface (TUI) modeled after a professional Bloomberg console. Built completely from scratch using Python and the `Textual` engine.

## 🚀 Features
* **Multi-Pane Dashboard Matrix:** Simultaneous monitoring fields built directly for terminal displays.
* **Live Volatility Tracking:** High-frequency, time-seeded ticker stream updating cells every second.
* **Autonomous Desk Carousel:** Automatic workspace desk rotation syncing macro data across top companies.
* **Financial News Wire:** Embedded live news layout simulator mimicking professional data infrastructure.

## 📦 How to Run Locally
Ensure you have Python installed on your system, then open your terminal window and initialize the terminal environment:

```bash
# Install the required interface engine components
python -m pip install textual

# Launch the interactive console layout
python terminal.py
```

## 🛠️ Built With
* **Python** - Core data pipelines and background timing loops.
* **Textual Engine** - Custom console stylesheet parsing and direct cell matrix rendering.
